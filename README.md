# winemenumgr

Ce logiciel vous permet de gérer le menu Démarrer de WineHQ sous GNU/Linux ainsi que sur WineHQ.

D'une part, notre menu est stocké dans « wine/programs » avec les applications ajoutées, et nous pouvons le déplacer vers « Démarrer/Tous les programmes », par exemple.

Nous pouvons déplacer le sous-menu « Office 2003 » contenu dans « wine/programs » vers « Démarrer/Tous les programmes ».

This software allows you to manage the WineHQ start menu on GNU/Linux and also on WineHQ.

On one side, we have our menu stored in “wine/programs” with the added applications, and we can move it to “Start/All Programs,” for example.

We can move the “Office 2003” submenu contained in “wine/programs” to “Start/All Programs.”
